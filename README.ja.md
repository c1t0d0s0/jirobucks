# JIROBUCKS (ジローバックス)

> **ラーメン二郎のコールとスターバックスのカスタム呪文をサクッと直感的に作成できるWebジェネレーター**  
> 「呪文」と恐れられる二郎のコールやスタバの複雑な注文を、スマホやPCからタップするだけで生成。店員に見せるモード、音声読み上げ、英語自動切り替えに対応！

---

## 🍜 コンセプト・背景

注文難易度が高いことで知られる**ラーメン二郎**と**スターバックス**：
- ラーメン二郎では、店主から突然投げかけられる「ニンニク入れますか？」の問いに対して、初心者がパニックになりがちです。「ヤサイマシマシアブラカラメ」といったコールを瞬時に唱えるのは緊張が伴います。
- スターバックスでも「トリプル・グランデ・ノンファット・ディカフェ・ホワイトモカ・エクストラホイップ・キャラメルソース追加」のように、まるで呪文のような複雑なカスタマイズが存在します。

**JIROBUCKS** は、直感的なUIで好みの条件を選択するだけで、誰でも自信を持って注文できる呪文・コールを即座に組み立てるツールです。

---

## ✨ 主な機能

- **🍜 ラーメン二郎モード**:
  - 食券提出時の注文（麺の量：普通・少なめ・半分・1/3、硬さ：普通・カタメ・バリカタ・ヤワメ）
  - トッピングコール（ニンニク・ヤサイ・アブラ・カラメ）
  - 「全マシ」「全マシマシ」などの短縮コール切り替え対応
- **☕ スターバックスモード**:
  - ベースドリンク（コーヒー、エスプレッソ、フラペチーノ、ティー・その他）
  - サイズ（Short / Tall / Grande / Venti®）＆ 温度（Hot / Iced）
  - ミルク変更（低脂肪・無脂肪・ソイ・アーモンド・オーツ・ブレベ）
  - エスプレッソ変更（ディカフェ・ブロンド・ショット追加・リストレット）
  - シロップ、ホイップ、ソース、フラペチーノ専用カスタム
  - バリスタが聞き取りやすい理想の順序で自然にフォーマット
- **🔥 推定カロリー & ユニーク指標（ギルティ度 / ダイエット指数）**:
  - 選択したカスタマイズに応じてリアルタイムで推定カロリー（約 ○○ kcal）を自動計算。
  - **二郎モード**: 「😈 ギルティ度: ★★★☆☆ (本格二郎)」〜「💥 ★★★★★ (ギルティ限界突破)」の5段階で背徳感を可視化！
  - **スタバモード**: 「🌿 ダイエット指数: ★★★★☆ (すっきり軽やか)」〜「🍰 ★☆☆☆☆ (悪魔的リッチ)」の5段階でヘルシー度を可視化！
- **📱 店員に見せる（巨大文字モード）**:
  - ワンタップで全画面に超巨大・高視認性の文字で呪文を表示。推定カロリーやトッピング詳細も一目で伝わり、声を出さずにそのままスマホ画面を店員さんに見せるだけでスマートに注文できます！
- **⚡ 定番クイックプリセット**:
  - 「全マシ」「王道二郎」「初心者安心」「チョモランマ」「トリプル・グランデ・ラテ」「悪魔の抹茶フラペチーノ」など、人気構成を1タップで呼び出し可能。
- **🌐 多言語自動対応（日本語 / 英語）**:
  - 日本語環境のブラウザには日本語、それ以外の言語環境には英語で自動表示。右上の言語ボタンでいつでも手動切り替え可能。
- **🔊 音声読み上げ（Web Speech API）**:
  - 作成した呪文を日本語音声で発音。並んでいる間に発声の練習ができます。
- **📋 クリップボードコピー & SNSシェア**:
  - 1タップで呪文をコピー、またはX（Twitter）にハッシュタグ付きで投稿。
- **🎲 おまかせ生成（ガチャ）**:
  - 運任せでユニークな美味しい組み合わせをランダム生成。
- **📖 初心者向けガイド & マナー集**:
  - 二郎のロットルールや丼の片付けマナー、スタバのサイズ一覧と無料・有料カスタムの違いを分かりやすく解説。
- **📊 Google Analytics 連携**:
  - `config.js` に `GTM_ID` が設定されている場合、自動でGoogle Analytics（GA4）タグを読み込みます。

## 🚀 ローカルでの動作確認方法

Node.jsやPythonなどのローカルHTTPサーバーで即座に実行できます。

### Python 3 を使用する場合:
```bash
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

### Node.js (npx) を使用する場合:
```bash
npx serve .
```

---

## ⚙️ Google Analytics の設定 (`config.js`)

`config.js` にて、お使いの測定ID（またはGTMコンテナID）を指定できます。

```javascript
const GTM_ID = 'G-S6QX2XHT2D';
```

※ `config.js` が存在しない場合や `GTM_ID` が空の場合は、自動的に読み込みをスキップしエラーなく動作します。
